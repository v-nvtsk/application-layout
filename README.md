# MFE Detail Layout — Настройки и Детальные Формы (MFE Detail Overlay)

Этот проект представляет собой демонстрационную реализацию архитектуры детальных форм (Settings MFE Detail Overlay) с использованием библиотеки компонентов дизайн-системы.

Основной фокус сделан на создании производительного, чистого и поддерживаемого кода с жестким следованием правилам дизайн-системы, отказом от JS-вычислений для лейаута и соблюдением современных архитектурных паттернов.

---

## 🎯 Наша цель
Создать надежную структуру оверлея детальной формы настроек (Detail Form Overlay), которая:
1. Соответствует гайдлайнам и дизайн-системе SberBusiness.
2. Не имеет проблем с перекрытием интерфейса: боковой статус-трекер (`StatusTracker`) должен корректно "залипать" (быть `sticky`) при скролле, сохраняя фиксированный отступ снизу от шапки страницы, высота которой может динамически меняться в разных разделах приложения.
3. Полностью исключает JS-подходы для расчета геометрии (такие как `ResizeObserver`, `useLayoutEffect` или слушатели событий `resize`), которые создают нагрузку на UI и могут вызывать мерцание.

---

## 💡 Концепция архитектуры

В рамках реализации мы руководствовались следующими ключевыми концепциями:

1. **Плоский (Flat) API компонентов**:
   Отказ от составных пространств имен вида `Application.Header` в пользу плоских изолированных экспортов (`Application`, `ApplicationHeader`, `ApplicationBody`, `ApplicationFooter`). Это упрощает типизацию, облегчает сборку (Tree Shaking) и исключает циклические зависимости.
   
2. **CSS-First Layout (Стилизация без JS)**:
   Все расчеты высоты шапки и позиционирования липких элементов вынесены в чистый CSS. В качестве интерфейса конфигурации используются явные CSS-переменные:
   - `--page-header-height`: Высота шапки страницы (индивидуальна для каждого типа хедера или экрана).
   - `--page-header-gap`: Расстояние от шапки до прилипающего статус-трекера.
   
3. **Строгое следование системным отступам**:
   Минимизация кастомных оберток, `margin` и `padding`. Применение стандартных отступов базовой библиотеки. Замена лишних `<Gap size={...} />` компонентов внутри колонок на CSS Flexbox `gap`, что делает разметку чище и семантически правильнее.
   
4. **Безопасные модальные окна**:
   Контролируемые оверлеи подтверждения действий (`TopOverlay`) для безопасного закрытия формы при наличии несохраненных изменений или при удалении конфигурации.

## 🛠️ Что сделано

1. **Создан плоский набор компонентов лейаута**:
   - В файле [Application.tsx](src/Module/components/ApplicationLayout/Application.tsx) определены основные блоки:
     - `Application` (с оберткой в `LightBox` и обработкой состояния загрузки/оверлеев).
     - `ApplicationHeader` (с кнопками печати и удаления).
     - `ApplicationBody` (на базе `Page.Body`).
     - `ApplicationFooter` (со стандартными действиями: Применить, Отмена, Подписать).

2. **Реализована детальная форма настроек**:
   - В файле [ApplicationDetail.tsx](src/Module/components/ApplicationDetail.tsx) разметка разделена на две колонки:
     - Левая колонка (`.detail-body-left`) содержит информационные острова (`Island`) с настройками. Для отступов между ними используется CSS-свойство `gap: 16px`.
     - Правая колонка (`.detail-body-right`) содержит прилипающий `StatusTracker`.
   - Внедрена система предупреждений при выходе с несохраненными данными и при попытке удаления.

3. **Оптимизировано позиционирование статус-трекера**:
   - В файле [App.css](src/Module/App.css) объявлены переменные на уровне `:root`.
   - Позиционирование статус-трекера реализовано через:
     ```css
     .detail-body-right {
       position: sticky;
       top: calc(var(--page-header-height) + var(--page-header-gap));
       z-index: 2;
     }
     ```
   - Добавлены явные комментарии, поясняющие, как и где менять значение высоты шапки в случае изменения ее структуры.

4. **Тематизация**:
   - Настроен дефолтный светлый режим (`LIGHT`) для провайдеров тем в [App.tsx](src/Module/App.tsx) и [HostApp.tsx](src/HostApp.tsx).

5. **Очистка кодовой базы**:
   - Удален неиспользуемый файл `DetailFormLayout.tsx`.
   - Из разметки удалены кастомные отступы и компоненты `<Gap>`, за исключением обоснованных случаев.
