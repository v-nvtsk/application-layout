# MFE Detail Layout & Codegen Demo

Этот проект представляет собой демонстрационную площадку для реализации детальных форм (Settings MFE Detail Overlay) с использованием библиотеки компонентов дизайн-системы SberBusiness (Triplex Next). 

Основная цель проекта — показать эволюцию подходов к построению форм, интегрировать полноценное сетевое макетирование (MSW) и предоставить инструмент для быстрого старта новых модулей.

---

## 🎯 Наша цель и архитектура

Мы сопоставили два архитектурных подхода к проектированию MFE-модулей:

1. **Подход на обёртках и слотах** (`ModuleExample` и `ModuleTemplate`):
   * Использование кастомных обёрток лейаута (`DetailsLayout`, `PrefillLayout`) и прокидывание контента через слоты (`headerSlot`, `contentSlot`).
   * **Плюсы**: Жёсткий контроль отступов на уровне обёрток, DRY.
   * **Минусы**: Ложная абстракция, переусложнённость, ограничения при кастомизации под специфические требования конкретных модулей.

2. **Плоский (Flat) подход на чистых компонентах** (`ModuleRawTemplate` — эталонный шаблон):
   * Отказ от промежуточных абстракций. Модули используют нативные компоненты библиотеки (`LightBox`, `Page`, `Island`, `StatusTracker`) напрямую.
   * **Плюсы**: Максимальная гибкость разметки, простота стилизации (включая липкие элементы, отступы и гриды), отсутствие скрытых зависимостей и упрощённое чтение кода.
   * **Рекомендовано как стандарт для разработки новых модулей**.

## 🛠️ Что реализовано в проекте

### 1. Реальный API-слой через MSW (Mock Service Worker)
Мы полностью отказались от локальных `setTimeout` и заглушек внутри хуков:
* Настроен полноценный перехватчик запросов в dev-режиме с помощью **MSW**.
* Созданы GET и POST эндпоинты `/api/v1/:moduleName/data` с симуляцией задержки сети и сохранением данных в in-memory хранилище на время сессии.
* Все хуки загрузки и сохранения переписаны на нативный `fetch()` с поддержкой отмены запросов через `AbortController`.
* Устранены любые предупреждения о каскадном рендере (`setState` внутри `useEffect`).

### 2. Автоматический CLI-генератор модулей
Для масштабирования плоского подхода разработан Node.js скрипт генерации:
* **Шаблон**: Копирует эталонный `ModuleRawTemplate`.
* **Переименование**: Автоматически переименовывает файлы (`ModuleDetail.tsx` → `QualificationDetail.tsx`, хуки `useFetchModuleData.ts` → `useFetchQualificationData.ts` и т.д.).
* **Замена строк**: Выполняет контекстную замену имен экспортируемых компонентов, типов, импортов и API эндпоинтов.

## 🚀 Как работать с проектом

### 1. Локальный запуск
Убедитесь, что зависимости установлены, и запустите dev-сервер:
```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev
```
Так как MSW (Mock Service Worker) работает целиком в браузере через механизм Service Worker, запускать отдельный mock-сервер не требуется. Vite dev-сервер — это единственный необходимый сервер. При открытии страницы в консоли браузера вы увидите сообщение `[MSW] Mocking enabled.`, а в сетевых запросах (Network tab) — перехваченные запросы к `/api/v1/.../data`.

> [!WARNING]
> Если в консоли возникает ошибка `[MSW] Failed to register the Service Worker: The operation is insecure`, убедитесь, что:
> 1. Вы открываете страницу в обычном окне браузера (Service Workers полностью отключены в приватных окнах / инкогнито-режиме).
> 2. Страница открыта на `http://localhost:...` (Service Workers требуют защищенного контекста HTTPS или localhost).

### 2. Генерация нового модуля
Чтобы создать новый модуль на базе плоского шаблона `ModuleRawTemplate`, выполните команду:
```bash
npm run create-module -- --name <ИмяМодуля>
```
Например:
```bash
npm run create-module -- --name Qualification
```
Скрипт создаст директорию `src/Modules/Qualification/` со всеми необходимыми компонентами, стилями и хуками, переименованными под ваш модуль, и выведет дальнейшие шаги по регистрации MFE.

## 📂 Структура директорий

* `src/mocks/` — конфигурация MSW, эндпоинты и in-memory база данных.
* `src/Modules/ModuleRawTemplate/` — **эталонный шаблон** на базе плоского подхода без обёрток (используется CLI-генератором).
* `src/Modules/ModuleExample/` — демонстрационный пример MFE на слотах и обёртках для сравнения.
* `src/Modules/ModuleTemplate/` — шаблон MFE на слотах и обёртках.
* `scripts/create-module.js` — код CLI-генератора.
